# Invented terms

50 synthetic financial terms with author-written definitions, each embedding one
arbitrary discrete fact, turned into four-option questions with balanced answer
positions and no term-name or option leakage.

These separate *reading an injected definition* from *recalling a memorised
one*. Because the terms do not exist, memorisation is impossible by
construction. In the paper both a frontier and a mid-capability model sit near
chance without the definition and answer every item correctly with it.

Each item has `id`, `term`, `definition`, `question`, `choices`, `answer`, where
`answer` indexes `choices`. Everything here is original to this work.
